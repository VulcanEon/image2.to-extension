## Chrome Web Store fields

### Single purpose description

This extension helps users quickly build GPT Image 2 prompts from reusable image-generation starters and optional custom details.

### Permissions justification

Storage is used only to remember the user's last selected starter and recent custom details inside the extension side panel.

### Remote code

No, this extension does not use remote code.
