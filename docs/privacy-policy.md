# Privacy Policy for image2.to GPT Image 2 Prompt Starter

image2.to GPT Image 2 Prompt Starter is a lightweight browser extension for building GPT Image 2 prompts from preset image-generation starters and optional custom details.

## Data collection

This extension does not collect, transmit, or sell personal data.

## Browser access

This extension does not read webpage content, browsing history, tab URLs, or form data on websites.

## Permissions

This extension runs in the browser side panel and only stores the user's latest starter selection and recent custom details inside the browser so the side panel can remember the last state.

## User input

Text entered into the extension is used only to generate the prompt shown in the side panel. The extension does not send that text to our servers.

## Open in image2.to

If you choose to continue on image2.to, you will be redirected to our website. Website use is governed by the image2.to site privacy policy.

You can review the site policy at https://image2.to/privacy-policy.
