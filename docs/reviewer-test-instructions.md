# Reviewer Test Instructions

No login, payment, or special credentials are required.

## How to test

1. Install the extension and pin it to the toolbar if needed.
2. Click the extension icon to open the side panel.
3. Select any prompt starter such as Product Shot or Brand Visual.
4. Optionally enter text in the Image details field.
5. Confirm that the GPT Image 2 prompt updates immediately.
6. Click Copy Prompt to copy the result.
7. Click Open in image2.to to continue on the website.

The extension does not read page content and works entirely from the side panel.
